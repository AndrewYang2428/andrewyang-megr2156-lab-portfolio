# A6 – Design Fits for an Artifact

## Parametric Design:

To get the parameters used for this assignment, I used a caliper to get the dimensions shown in the rough sketch. The main parameters that matter the most for this assignment were the diameter of the stepper motor, the diameter of the holes in the brackets around the motor, and the distance between the holes to get the correct fit. These parameters will allow for a snug fit of the motor when it is finally printed out. Once I had these parameters, I created features that I thought would make this design work properly and adjusted them based on the material that was used, which was PETG. The overall motor mount dimension was based on the size of the motor, so I based the exterior of the design on the motor dimensions. This design gives a general view of the face of the motor mount bracket with the parameters needed to snap the motor onto the motor mount.

## Documentation:

### Overview:

For this assignment, I designed a snap-fit artifact that snaps onto a stepper motor (28BYI-48). The motor has brackets that can be used to screw onto a motor mount, so taking this idea, I designed my motor mount to simply allow the motor to snap onto the motor mount using the built-in bracket that the stepper motor already has on it. The overall size of my snap-fit design is 2 in. x 2 in. with a thickness of 0.25 in. For this design, I placed it flat, facing up, to have more focus on the snap feature that I designed to make it the most accurate. Since there was a slight overhang, I had to use supports to ensure that it came out the way I wanted it to. The overhang was not very large, so the supports did add some material that affected the fitment of the snap feature of my design. The settings were all on default because they didn't have any impact or effect on my design, so I left that alone to keep the print process simple and easy to complete. There were many changes that were made throughout the process to get the fit of this design correct. I mainly had to change dimensions and add features to my design to get the snap fit that was expected for this assignment. With these changes, I was then able to find the general dimensions and fitment for the snap fit design.

## Lessons Learned:

For this assignment, there were many trial-and-error moments because small dimensions were used to make this happen. When dealing with measurements in the thousandths, as well as working with the material made it hard to get the dimensions needed to make this snap fit work. My final design does have a snap fit, but it is not able to come off and re-snap again. A lesson learned for this assignment was to pay more attention to the material properties because this will help you determine if your design will come out the way you want it to or not. I learned that getting precise measurements makes designing easier, but since this assignment involves a thousandth of an inch, it makes it hard to get a perfect fit of a part. The snap fit feature allows for much practice in what we have learned from previous assignments and projects, bringing what we learned from all of the topics and applying it to make a design work precisely. I've learned many things from this project and hope to continue growing from here on.
